# Tree icon artwork

`tree-icon-source.png` is the selected silver-gray T-button artwork for Tree's
web app icon. It is the original generated image, including its surrounding
background and soft shadow.

The web app icons in `src/web/public/` (`icon-512.png`, `icon-192.png` and
`apple-touch-icon.png`) are exports of this artwork: cropped to the rounded tile,
with transparent corners and without the background or shadow. Regenerate them
from this file when the artwork changes; PRODUCT §24.1 defines their use.
